## 각 이슈에서 실제로 판단한 것

### #149 — 옮긴 기능은 이름을 들고 간다

툴바 26개 중 단축키가 없는 `부가` 묶음 6개를 팝오버로 옮겼더니
`.toolbar-btn[title="…"]` 을 쓰던 **E2E 6개 파일이 한꺼번에 죽었다.**

고친 방향은 셀렉터를 스무 군데 바꾸는 것이 아니라, 항목에 `data-action` 으로
**원래 이름을 남기고** `fixtures.ts` 에 `clickToolbarAction()` 을 두는 것이었다 —
"툴바에 있으면 누르고, 없으면 팝오버를 연다". 그래야 **옮긴 것과 없앤 것이
구별된다**(없앤 기능은 여전히 실패한다).

`<dialog>` 를 쓰지 않은 이유: 모달은 뒤를 어둡게 하고 스크롤을 막아
"인쇄 전에 문서를 한 번 더 본다" 같은 흐름을 끊는다. 대신 Esc·포커스 복귀·
화살표 이동·바깥 클릭을 직접 만들었다.

### #150 — 미리보기와 삽입은 같은 함수에서 나와야 한다

`makeTableBlock()` 을 뽑아 `buildTable()` 과 미리보기가 함께 쓴다. 각자 계산하면
"보이는 것과 넣은 것이 같다" 가 우연이 되고, 그 갈라짐은 **넣어 본 사용자만**
발견한다.

미리보기는 마크다운을 만들지 않고 `<table>` 로 그린다 — 문자열을 만들어 다시
파싱하면 렌더 경로가 둘이 되고, 화면에서 파이프 정렬은 아무 의미도 없다.
그래서 `displayWidth()` 는 여기 쓰이지 않는다. 표시 폭 계산은 마크다운을
만드는 `formatTable()` 의 일이고, TP5 가 넣은 표의 세로줄을 표시 폭으로 단언한다.

### #151 — 차례를 손으로 적지 않는다

절을 더할 때 두 곳을 고쳐야 하면 잊게 되고, 그러면 빌드도 테스트도 통과하면서
**차례만 낡는다**(트랩 #22 아이콘 사고와 같은 구조). 차례는 **그려진 본문의
`h2`** 에서 만든다 — 원문을 다시 파싱하지 않으므로 정화 경로도 갈라지지 않는다.

### #152 — 본체는 "언제 계산하느냐" 였다

이슈가 요구한 대로 먼저 측정했다(Node 24, 200회 평균):

| 문서 크기 | 줄 시작 배열 생성 | 이진 탐색 | 선형 탐색 |
|---|---|---|---|
| 9,289자 | 0.016ms | 0.02µs | 0.014ms |
| 94,889자 | 0.088ms | 0.01µs | 0.095ms |
| 478,889자 | 0.479ms | 0.01µs | 0.472ms |

**선형 탐색은 배열을 통째로 다시 만드는 것과 비용이 같다.** 그래서 배열은 본문이
바뀔 때만 만들고 캐럿 이동에서는 이진 탐색만 한다.

### #153 — 로직을 건드리지 않는다는 제약이 답을 정했다

`notice.ts`·`search.ts`·`editorSettings.ts` 는 한 줄도 바뀌지 않았다. 검색 바도
요소를 옮기지 않고 도크로 감싸기만 해서 토글 JS(`aria-controls`)를 지켰다.

## 의도적 버그 주입 — 이번 회차의 수확

5개 이슈에서 47건을 주입해 **39건이 잡혔다.** 잡히지 않은 8건이 이번 작업에서
가장 값이 컸다.

| 안 잡힌 것 | 무엇이었나 | 어떻게 했나 |
|---|---|---|
| `pointerdown` → `click` (#149) | 트리거를 걸러내므로 **두 방식이 구별되지 않는다** | 주석의 "필연" 주장을 사실로 고침 |
| `editsText` 재발행 제거 (#149) | `execCommand` 가 `input` 을 네이티브로 쏜다 | 단언 문구에서 그 근거 주장을 뺌 |
| 행 입력 리스너 제거 (#150) | 열 입력 리스너가 다시 그리며 **가렸다** | 입력별로 단언을 쪼갬 |
| 링크 `preventDefault` 제거 (#151) | 화면은 멀쩡히 이동, **주소에 해시만 남음** | 스크롤 대신 **주소**를 단언 |
| 재열기 `markActive(0)` (#151) | 스크롤 리스너가 이미 하는 일 | **중복이라 삭제** |
| `input`·`keyup`·`click` 리스너 (#152) | 전부 `selectionchange` 로 온다 | **셋 다 삭제** |
| 캐시·이진탐색 (#152) | `selectionchange` 가 작업당 한 번으로 합쳐져 **측정 자체가 불가능** | 코드와 트랩에 "값이 싸서 둔다" 고 명시 |
| `appearance: none` 제거 (#153) | 색·손잡이 단언은 통과, 화면엔 네모 체크박스 | 겉모습 자체를 단언 |

**세 건은 코드를 지우는 것으로 끝났다.** 구별되지 않는 배선은 다음 사람이
"필요하다" 고 믿게 만든다.
