# 2026-08-14 · 비개발자용 동작 해설 문서 (`/aiops:explain-app`)

## 1. 요청 사항

> `/aiops:explain-app markdownEditor`

개발 지식이 없는 사람(동료·고객·경영진)이 읽을 수 있는 **구조 해설 문서**를 만든다. 기존 개발자 문서를 요약하는 것이 아니라 **코드를 근거로 다시 쓴다.**

## 2. 결과

| 산출물 | 위치 |
|--------|------|
| 정본 | [`docs/how-it-works.md`](../how-it-works.md) (머메이드 5장) |
| 게시본 | Artifact HTML (손 SVG 4장, 라이트·다크) |

## 3. 문서 위치를 `docs/apps/` 로 하지 않은 이유

스킬의 기본 경로는 `docs/apps/<앱>.md` 다. 이 저장소는 **앱이 하나**라서 그 경로를 쓰면 항목이 하나뿐인 폴더가 생기고, `docs/` 가 주제별(architecture·api·features·testing·operations)로 나뉜 기존 관례와 어긋난다. 이미 `docs/user-scenarios.md` 가 최상위에 있는 선례가 있어 같은 층에 두고, 다음 실행이 같은 판단을 재현하도록 `git config aiops.explainDocsDir docs` 를 기록했다.

## 4. 색을 이 앱에 맞게 재배정했다

시리즈의 규칙은 **색 = 위치**다. 원래 배정은 `--cf`(클라우드) · `--mac`(LLM 서버)인데 이 앱에는 연산 백엔드가 없다. 스킬 지침대로 두 색을 버리지 않고 다시 배정했다.

| 토큰 | 이 문서에서의 뜻 |
|------|------------------|
| `--cf` | 브라우저 안에서 끝나는 일 |
| `--mac` | 클라우드로 나가는 일 (버튼을 눌렀을 때만) |
| `--warn` | 거절 · 실패 |

## 5. 고른 그림과 그 주장

| 그림 | 주장 |
|------|------|
| 여정도 | **경계를 넘는 화살표가 둘뿐이다** — 대부분의 일이 브라우저 띠 안에서 끝난다 |
| 정화 관문 | 화면에 그리는 길이 **하나뿐**이라 남이 만든 문서를 열어도 된다 |
| 스크롤 비교 | 비율로 맞추면 숫자는 맞고 **내용이 어긋난다**. 문단 짝은 오차를 문단 안에 가둔다 |
| 공유 관문 | 밖으로 나가는 것은 글자 원문뿐이고, 거절 문구는 사용자가 실제로 보는 문장이다 |

`구성 요소 나열`·`폴더 구조` 같은 그림은 그리지 않았다 — 표가 낫거나 비개발자에게 의미가 없다.

## 6. 검수에서 고친 것

브라우저로 열어 확인한 결과 **첫 그림의 경계 화살표 라벨이 점선과 겹쳐** 있었다. 두 점선의 꺾이는 높이를 갈라(y=178 / y=246) 라벨이 각자의 가로 구간 위에 놓이도록 고쳤다.

그 밖에 확인한 것: 왼쪽 거터 라벨 잘림 없음(viewBox x 를 음수로 둠) · 그림의 가로 스크롤이 프레임 안에서만 일어남 · 토큰 블록 밖에 하드코딩된 색 0건(다크 모드 안전).
