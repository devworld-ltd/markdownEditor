## #146 — 이슈에 적은 것보다 컸다

"색 값 재매핑" 으로 적었는데 열어 보니 **툴바와 탭바가 `#1e1e1e`·`#252526` 로
하드코딩**돼 있었다. 앱의 나머지는 테마를 따르는데 머리만 안 따라서, 라이트
모드에서 검은 띠가 남아 있었다. `#007acc` 도 11곳에 흩어져 있었다.

**이번 묶음에서 사용자가 가장 크게 체감할 변화가 이것이다.**

### 디자인을 그대로 따르지 않은 판단 둘

**1. 툴바와 탭바를 한 색으로 합치지 않았다.**
디자인은 `chrome` 하나로 그렸지만 `darkmode.spec.ts` 의 D3 가 **"툴바 < 탭바 <
에디터 < 프리뷰" 4단 명도 계단**을 단언한다. F-72 의 "원재료 → 완성물" 읽기
방향이고, 내 디자인 편의로 조용히 약화시킬 이유가 없어 두 단으로 나눴다.

**2. `--text-faint` 를 글자에 쓰지 않기로 했다.**
본문 > 보조 > 라벨 3단계를 만들려 했는데, **라이트 툴바 표면에서
`--text-muted`(#666)가 이미 4.67** 이라 그보다 옅으면서 4.5:1 을 넘는 값이
**존재하지 않는다.** 억지로 두면 읽히지 않는 라벨이 생기므로 라벨도 muted 를 쓰고,
faint 는 아이콘·구분선 전용(3:1)으로 역할을 좁혔다. (트랩 #86)

`--status-warn` 은 처음 `#9a6400` 이었으나 툴바 표면에서 **4.07 로 AA 미달** —
새 TK3 테스트가 잡아 `#8a5900` 으로 내렸다.

### 테스트를 값이 아니라 관계로 썼다

`tokens.spec.ts` 11건은 **색 값을 단언하지 않는다.** 값은 앞으로도 손볼 것이고,
고정하면 조정할 때마다 깨져 결국 지워진다. 대신 깨지면 안 되는 관계를 본다:
양쪽 모드에 값이 있는가 · 네 표면에서 AA 인가 · 계단 방향이 맞는가 ·
하드코딩이 남아 있지 않은가.

## #147 — 버튼을 하나도 빼지 않았다

디자인은 26개 → 20개 + 더보기다. 그런데 **코드 블록 · 구분선 · HTML 내보내기 ·
HTML 복사는 단축키가 없다**(`shortcutDefs.ts` 확인). 더보기 팝오버(#149)가 아직
없는데 지금 빼면 **마우스로도 키보드로도 닿을 수 없게 된다.**

이슈 본문에는 "그때까지 `⋯` 는 비활성으로 둔다" 고 적혀 있었지만 그대로 하면
4개 기능이 고립된다. `부가` 묶음으로 모아 두기만 했고, E2E 가 "단축키 없는 기능이
툴바에 남아 있다" 를 단언해 실수로 먼저 빼는 것을 막는다.

### 구분선을 손으로 놓지 않는다

`separator: true` 를 버튼마다 붙이던 방식이었는데, 버튼을 하나 옮기면 그것도 같이
옮겨야 하고 **어긋나도 화면에서만 티가 나고 타입은 통과한다.** 묶음 순서를
`GROUP_ORDER` 데이터로 두고 경계에서 자동 생성하도록 뒤집었다.

**묶음은 눈으로만 나뉘지 않는다** — 구분선은 스크린리더에게 아무 뜻도 아니므로
각 묶음을 `role="group"` + `aria-label` 로 감쌌다.

## #148 — 통계와 다른 경로

저장 여부를 알 수 있는 곳이 **탭의 작은 점 하나뿐**이었다.

- **색만으로 알리지 않는다** — 글자가 본체이고 아이콘은 거드는 것
- **`aria-live` 를 붙이지 않는다** — 붙이면 타이핑마다 스크린리더가 읽어 편집이
  불가능해진다 (트랩 #56). SS6 가 두 속성의 부재를 단언
- **새 문서는 dirty 가 아니라 "저장한 적 없음"** — 저장할 곳이 정해지지 않았다는
  것이 더 중요한 정보다

통계는 매 글자마다 전체를 훑어야 해서 150ms 디바운스에 얹혀 있지만, 저장 상태는
dirty 가 바뀔 때만 달라진다. `renderTabs()` 가 dirty·파일명·탭 전환의 **단일
통로**라 거기에 `setTabStateListener` 를 새로 걸었다 — 기존 `setTabRenderListener`
를 재사용하지 않은 이유는 그쪽이 앵커·mermaid 재계산까지 딸고 오기 때문이다.

## 사고 — `git checkout` 이 커밋 안 된 작업을 지웠다

#148 에서 의도적 버그 주입을 되돌릴 때 `git checkout src/main.ts` 를 썼다. 주입한
한 줄만 되돌아갈 줄 알았지만 **그 파일의 커밋되지 않은 변경 전체**가 날아갔다 —
저장 상태 배선이 통째로 사라진 채 커밋됐다.

로컬 E2E 는 지우기 **전에** 통과했고 지운 뒤 다시 돌리지 않아 못 봤다.
**CI 가 saveState E2E 7건 실패로 잡았다.**

되살린 뒤 `CI=1` 로 재현 확인했다. **이 세션에서 두 번째 같은 실수**라
`CLAUDE.md` 트랩 87 로 남겼다 — 주입 롤백은 `/tmp` 사본으로만.

> 로컬에서 통과한 뒤 파일을 되돌렸으면 **다시 돌려야 한다.** 이것이 이번 사고의
> 한 줄 요약이다.

## Pencil 작업에서 겪은 것

- `ref` 인스턴스를 일반 화면 프레임에 `Insert` 하면 **렌더되지 않는다.** `Copy` 는
  된다 — 원인은 못 밝혔고 `Copy` 로 우회했다
- 작업 중반부터 **새로 만든 노드가 스크린샷·내보내기에서 그려지지 않았다.** 기존
  프레임은 정상이었다. 데이터는 구조 점검(문제 노드 0건)으로 확인했고, 마지막 세
  화면(`06 좁은 화면`·`13 더보기`·`14 알림`)은 **눈으로 확인하지 못했다**
