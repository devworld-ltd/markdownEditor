## 3. 테스트가 잡은 실제 결함 4건

이번 체인의 성과는 기능 4개가 아니라, **눈으로는 안 보이지만 배포되면 사용자가 겪었을 것들**을 테스트가 먼저 잡은 것이다.

| # | 결함 | 왜 눈에 안 띄나 |
|---|------|----------------|
| 1 | `textarea` 가 `color` 를 상속하지 않아 **다크 모드에서만** 검은 글씨가 어두운 표면에 남는다 | 라이트로 개발하는 동안에는 보이지 않는다. E2E 가 대비 **1.47:1** 로 잡았다 |
| 2 | 전역 리셋 `* { margin: 0 }` 이 UA 의 `dialog:modal { margin: auto }` 를 덮어써 모달이 **화면 좌상단에 붙는다** | 기능은 멀쩡하다. 백드롭 클릭 테스트가 좌표로 잡았다 |
| 3 | 검색이 에디터로 포커스를 뺏어 **Enter 가 본문에 개행을 넣고 방금 찾은 일치를 지운다** | 한 번 눌러 보기 전에는 모른다. E2E 가 `1/3 → 1/2` 로 잡았다 |
| 4 | 아이콘 생성기의 곡선 거부 가드가 **한 번도 실행되지 않았다** — 토크나이저가 `C` 를 아예 버려 곡선이 직선으로 조용히 파싱됐다 | 가드가 있다는 사실 자체가 안심을 준다. 주입 검증에서만 드러난다 |

4번은 트랩 #16(단언 검증)의 생성기 버전이다. **가드를 넣었으면 그 가드가 실제로 걸리는지 확인해야 한다.**

## 4. 설계 판단

### F-57 — 다크 전용 레이아웃 분기를 **하나도** 만들지 않았다

미디어 쿼리에서 토큰 값만 바꾸고 규칙은 라이트 정의를 그대로 쓴다. 그래서 F-72 시각 구분과 720px 이하 2px 가로 경계가 자동으로 따라온다. 분기를 두 벌 만들면 한쪽만 갱신되는 사고가 난다.

툴바·탭바는 손대지 않았다 — 라이트에서도 이미 어두워서, 그대로 두면 명도 계단이 다크에서도 같은 방향으로 유지된다.

### F-68 — 새 의존성 0개로 래스터화

`sips`(macOS 전용)·`rsvg-convert`(시스템 설치)·`sharp`(네이티브) 중 무엇을 골라도 이식성이나 의존성 성질을 잃는다. 이 아이콘은 둥근 사각형 + 직선 폴리곤뿐이라 정확한 기하 판정이 가능했고, `node:zlib` 만으로 PNG 를 인코딩했다.

**full-bleed 와 둥근 모서리를 나눈 것**이 핵심이다. iOS 와 maskable 소비자는 자기 마스크를 덧씌우므로 이미 둥근 이미지를 주면 모서리가 두 번 깎인다. 기존 매니페스트는 같은 SVG 를 `any` 와 `maskable` 양쪽에 선언해 이 구분이 아예 없었다.

### F-58 — 안내가 낡는 것을 구조적으로 불가능하게

```
shortcutDefs.ts  (유일한 정의)
   ├── shortcuts.ts     디스패치
   └── shortcutHelp.ts  안내 렌더
```

안내 UI 의 가장 흔한 실패는 목록이 실제 동작과 어긋나는 것이다. **안내가 거짓말하는 것은 안내가 없는 것보다 나쁘다.** 테스트로 잡기보다 불가능하게 만드는 편이 낫다. 디스패치가 `Record<ShortcutId, …>` 라 정의만 늘리고 동작을 빠뜨리면 컴파일이 막는다.

이 투자는 **바로 다음 항목에서 배당금을 냈다** — F-22 에서 단축키를 정의에만 추가하자 안내 목록에 검색이 자동으로 나타났다.

### F-22 — 서수 보존

`remapIndex` 를 "가장 가까운 위치" 로 먼저 만들었으나 흔한 경우에 어긋났다. 앞에 네 글자를 끼우면 모든 일치가 4씩 밀려 세 번째보다 두 번째가 예전 좌표에 가까워지고, 하이라이트가 뒤로 튄다. 타이핑은 대개 개수를 바꾸지 않고 좌표만 밀므로 서수 보존이 지배적인 경우에 항상 옳다.

## 5. 지우거나 인정한 것

- **버튼 클릭 후 rAF 선택 재적용을 넣었다가 지웠다.** 제거해도 아무 테스트가 실패하지 않아 방어할 대상이 없음을 확인했다. 트랩 #2 는 탭바 클릭 경로의 이야기다.
- **`go()` 의 재계산은 E2E 로 검증되지 않는다.** `onAfterRender → refresh()` 가 탭 전환을 대신 처리해 가린다 — 지워도 E2E 는 전부 통과했다. 렌더 알림 없이 `value` 만 바꾸는 단위 테스트로 못을 박았다.
- **테스트 브라우저 UA 가 Windows** 라 `⌘` 표기 분기가 한 번도 실행되지 않았다. 단위 테스트와 UA 를 바꾼 E2E 로 양쪽을 덮었다.
