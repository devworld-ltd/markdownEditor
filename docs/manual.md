# 사용 설명서

마크다운 에디터를 **어떻게 쓰는지** 설명합니다. 설치 없이 주소만 열면 바로 쓸 수 있습니다.

> 이 문서는 앱 안에서도 볼 수 있습니다 — 툴바의 **책 아이콘**을 누르세요.

## 1. 처음 열었을 때

화면은 둘로 나뉩니다.

| 왼쪽 | 오른쪽 |
|------|--------|
| **편집 영역** — 글을 씁니다 | **미리보기** — 결과가 바로 보입니다 |

화면이 좁으면(720px 이하) 위아래로 나뉩니다. 가운데 경계선을 끌면 비율을 조절할 수 있고, 그 비율은 다음에 열 때도 유지됩니다.

**쓴 글은 저절로 보관됩니다.** 창을 닫았다 다시 열어도 그대로 있습니다. 다만 그것은 이 브라우저 안에만 있는 사본이므로, 오래 간직할 글은 파일로 저장하세요.

## 2. 글쓰기

마크다운 문법을 그대로 쓰면 됩니다. 문법을 몰라도 툴바 버튼으로 넣을 수 있습니다.

| 하고 싶은 것 | 쓰는 법 |
|---|---|
| 제목 | `# 제목` `## 소제목` `### 더 작은 제목` |
| 굵게 / 기울임 | `**굵게**` / `*기울임*` |
| 취소선 | `~~취소선~~` |
| 목록 | `- 항목` 또는 `1. 항목` |
| 인용 | `> 인용문` |
| 링크 | `[보이는 글](주소)` |
| 코드 | `` `한 줄 코드` `` 또는 ``` 로 감싼 여러 줄 |
| 구분선 | `---` |

### 편하게 만들어 주는 것들

- **목록 이어쓰기** — 목록 항목에서 Enter 를 누르면 다음 항목이 저절로 생깁니다. 빈 항목에서 Enter 를 한 번 더 누르면 목록에서 빠져나옵니다.
- **Tab 들여쓰기** — 목록 안에서 Tab 으로 한 단계 들어가고, Shift+Tab 으로 나옵니다.
- **되돌리기** — 툴바로 넣은 것도 전부 `⌘Z`(Windows·Linux 는 `Ctrl+Z`)로 되돌아갑니다.

> **Tab 키에 갇히지 않습니다.** Esc 를 누른 뒤 첫 Tab 은 다음 요소로 넘어갑니다 — 키보드만으로 쓰는 분을 위한 탈출구입니다.

## 3. 표 만들기

툴바의 **표 버튼**을 누르면 칸 수를 정해 넣을 수 있습니다. 커서가 이미 표 안에 있으면 그 표를 **편집**하는 창이 열립니다.

정렬은 구분줄로 정합니다.

```
| 왼쪽 | 가운데 | 오른쪽 |
|:-----|:-----:|------:|
| 가   |  나   |    다 |
```

한글과 이모지는 알파벳보다 넓어서, 이 앱은 **보이는 너비**로 세로줄을 맞춥니다.

## 4. 그림·다이어그램

### 이미지

이미지 파일을 편집 영역에 **끌어다 놓거나 붙여넣으면** 됩니다. 문서 안에 함께 담깁니다.

받는 형식은 PNG · JPEG · GIF · WebP 입니다. **SVG 는 받지 않습니다** — 그림처럼 보이지만 실제로는 프로그램을 담을 수 있는 문서라, 열었을 때 위험할 수 있습니다.

### 다이어그램

` ```mermaid ` 로 시작하는 코드 블록에 순서도를 쓰면 그림으로 그려집니다.

````
```mermaid
flowchart LR
  A[시작] --> B[진행] --> C[끝]
```
````

문서에 다이어그램이 하나도 없으면 관련 파일을 아예 내려받지 않으므로, 안 쓰는 분에게는 앱이 느려지지 않습니다.

### 각주와 용어 설명

```
본문에 각주를 답니다[^1].

[^1]: 각주 내용입니다.

용어
: 그 용어의 뜻입니다.
```

## 5. 파일 다루기

| 하고 싶은 것 | 방법 |
|---|---|
| 새 문서 | 툴바 **New** · `⌥N` (Windows·Linux `Alt+N`) |
| 파일 열기 | 툴바 **Open** · `⌘O` / `Ctrl+O` · 파일을 끌어다 놓기 |
| 저장 | 툴바 **Save** · `⌘S` / `Ctrl+S` |
| 다른 이름으로 저장 | `⌘⇧S` / `Ctrl+Shift+S` |
| 최근에 연 파일 | 툴바 **시계 아이콘** |

### 브라우저에 따라 다릅니다

| | Chrome · Edge | Safari · Firefox |
|---|---|---|
| 저장 | 열었던 그 파일에 **덮어씁니다** | 저장할 때마다 **내려받기 폴더**로 새로 받습니다 |
| 같은 파일 두 번 열기 | 이미 열린 탭으로 이동 | 탭이 하나 더 생깁니다 |

Safari·Firefox 는 브라우저가 파일에 직접 쓰는 기능을 아직 지원하지 않아서입니다. 처음 저장할 때 이 차이를 한 번 알려 드립니다.

### 최근 파일 목록

목록의 항목마다 상태가 함께 표시됩니다.

| 표시 | 누르면 |
|---|---|
| (시각만) | 바로 열립니다 |
| **접근 허용 필요** | 파일 접근을 한 번 허용하면 열립니다 |
| **다시 선택 필요** | 파일 선택 창이 열립니다 |

새로고침해도 파일 위치가 보관되므로(Chrome·Edge), 대개는 허용 한 번으로 바로 열립니다.

### Finder에서 바로 열기 (macOS)

Chrome·Edge 에서 이 앱을 **설치**하면(주소창 오른쪽 설치 아이콘), Finder 에서 `.md` 파일을 우클릭했을 때 **"다음으로 열기"** 목록에 이 앱이 나타납니다. 앱 창이 이미 떠 있다면 새 창이 또 열리지 않고 **그 창에 탭으로** 추가됩니다.

### 다른 곳에서 바뀐 파일 다시 읽기

다른 편집기나 동기화 도구로 같은 파일을 고쳤다면, 이 앱으로 돌아왔을 때(창을 다시 클릭하거나 탭을 바꿀 때) 변경을 알아챕니다.

| 상황 | 일어나는 일 |
|---|---|
| 편집 중이 아니었다면 | 자동으로 최신 내용을 다시 읽고 알려 드립니다 |
| 편집 중이었다면 | **본문은 그대로 두고** 탭에 `⚠` 표시와 안내 줄이 뜹니다 — "다시 읽기"와 "내 내용 유지" 중 고를 수 있습니다 |

수동으로 확인하려면 툴바의 **다시 읽기**(⟳) 버튼이나 `⌥R`(Windows·Linux `Alt+R`)을 씁니다. 파일 선택 창으로 열지 않은 문서(붙여넣기·새로고침 뒤 복원된 문서 등)에서는 이 버튼이 흐리게 표시됩니다 — 다시 읽어 올 원본 파일 위치를 모르기 때문입니다.

저장하려는 순간 그 파일이 디스크에서 이미 바뀌어 있었다면, 덮어쓰기 전에 한 번 더 확인합니다 — 모르는 사이에 남의 변경을 지우지 않기 위해서입니다.

## 6. 여러 문서 동시에

위쪽 **탭 막대**로 문서를 여러 개 열어 둘 수 있습니다.

- 탭을 끌어서 순서를 바꿉니다 (`⌥⇧←` `⌥⇧→` 로도 됩니다)
- 탭 닫기는 `⌥W` (Windows·Linux `Alt+W`)
- 저장하지 않은 탭에는 **점**이 표시되고, 닫거나 창을 나갈 때 확인합니다

## 7. 찾기와 바꾸기

`⌘F` / `Ctrl+F` 로 검색창을 엽니다.

- Enter 로 다음, Shift+Enter 로 이전
- **바꾸기**와 **모두 바꾸기**를 함께 쓸 수 있습니다
- 모두 바꾸기도 `⌘Z` 한 번으로 되돌아갑니다

## 8. 내보내기·공유·인쇄

| 하고 싶은 것 | 방법 | 결과 |
|---|---|---|
| HTML 파일로 | 툴바 **Export HTML** | 혼자서도 열리는 파일 하나 |
| 다른 곳에 붙여넣기 | 툴바 **Copy HTML** | 서식이 유지됩니다. 서식을 모르는 곳에는 원문이 들어갑니다 |
| 링크로 공유 | 툴바 **공유** | 주소가 복사됩니다 |
| 인쇄 / PDF | 툴바 **인쇄** · `⌘P` / `Ctrl+P` | 인쇄 창의 "PDF로 저장" |

> **공유는 이 앱에서 유일하게 인터넷을 쓰는 기능입니다.** 버튼을 누른 그 문서만 서버에 올라갑니다. 공유를 쓰지 않으면 글은 이 컴퓨터를 벗어나지 않습니다.

## 9. 화면 조절

| | |
|---|---|
| **보기 모드** | 툴바 **View Mode** · `⌥M` — 분할 → 편집만 → 미리보기만 순환 |
| **글꼴·크기** | 툴바 **Settings** — 편집 영역에만 적용됩니다 |
| **줄 번호·통계·하이라이팅** | 툴바 **Settings** 에서 켜고 끕니다 |
| **어두운 화면** | 운영체제 설정을 따라갑니다 |

글꼴 설정이 편집 영역에만 적용되는 이유는, 내보내거나 인쇄한 결과가 **받는 사람 쪽에서 일정해야** 하기 때문입니다.

## 10. 단축키

전체 목록은 툴바의 **키보드 아이콘**(또는 `⌥/`)에서 볼 수 있습니다. 이 목록은 항상 실제 동작과 같습니다.

| 기능 | macOS | Windows · Linux |
|---|---|---|
| 파일 열기 | `⌘O` | `Ctrl+O` |
| 저장 | `⌘S` | `Ctrl+S` |
| 다른 이름으로 저장 | `⌘⇧S` | `Ctrl+Shift+S` |
| 문서 내 검색 | `⌘F` | `Ctrl+F` |
| 새 문서 | `⌥N` | `Alt+N` |
| 탭 닫기 | `⌥W` | `Alt+W` |
| 탭 옮기기 | `⌥⇧←` `⌥⇧→` | `Alt+Shift+←` `→` |
| 디스크에서 다시 읽기 | `⌥R` | `Alt+R` |
| 보기 모드 전환 | `⌥M` | `Alt+M` |
| 단축키 목록 | `⌥/` | `Alt+/` |

새 문서와 탭 닫기가 `⌘N`·`⌘W` 가 아닌 이유는, 그 조합을 **브라우저가 먼저 가져가** 막을 수 없기 때문입니다.

## 11. 인터넷이 끊겼을 때

한 번 방문한 뒤에는 **인터넷 없이도 열립니다.** 끊긴 동안에는 화면에 표시가 뜨고, 편집·저장은 그대로 됩니다. 공유만 되지 않습니다.

새 버전이 나오면 알림이 뜹니다. 눌러서 새로고침하면 적용되고, **무엇이 바뀌었는지**는 상태 표시줄의 버전(`v2.2.0` 같은 표시)을 눌러 확인할 수 있습니다.

## 12. 잘 안 될 때

| 증상 | 이유와 대처 |
|---|---|
| 저장했는데 원래 파일이 안 바뀜 | Safari·Firefox 는 내려받기 폴더로 받습니다. 덮어쓰려면 Chrome·Edge 를 쓰세요 |
| 최근 목록을 눌렀는데 파일 선택 창이 뜸 | 그 항목이 **다시 선택 필요** 상태입니다 — 이 브라우저에 파일 위치가 남아 있지 않습니다 |
| 자동 보관이 멈췄다는 알림 | 브라우저 저장 공간이 찼습니다. 안 쓰는 탭을 닫으면 정리됩니다. 중요한 글은 파일로 저장하세요 |
| 이미지를 넣을 수 없음 | SVG 는 받지 않습니다. 크기 제한도 있습니다 |
| 다이어그램이 안 그려짐 | 문법 오류가 있으면 코드 블록 아래에 이유가 표시됩니다 |
| 시크릿 창에서 글이 사라짐 | 시크릿 창은 창을 닫을 때 저장소를 비웁니다 |
