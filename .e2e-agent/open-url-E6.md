# E2E 시나리오: 남이 준 문서의 스크립트가 실행되지 않는다 (E6, AC-11)

대상 앱: {base_url}/?url=<대상 주소>

## 목표
링크로 받아온 원격 문서 안에 스크립트나 위험한 속성이 숨어 있어도, 이 앱의 기존 안전 처리 과정을 그대로 거쳐 전부 무력화된다. 남의 문서를 여는 기능이 곧 공격 경로가 되면 안 된다.

## 사전조건
대상 주소가 주는 문서 본문은 다음을 포함한다: 제목 하나, 스크립트를 실행하려는 태그, 이미지 로드 실패를 이용해 스크립트를 실행하려는 속성, 그리고 눌렀을 때 스크립트를 실행하려는 링크. 이 앱에는 로그인이 없다. e2e_user/e2e_pass 는 사용하지 않는다.

## 수행 단계 (순서대로, 순수 자연어)
1. 대상 주소로 진입해 확인 대화상자에서 "열기"를 누른다.
2. 미리보기 영역을 확인한다.
3. 미리보기 안에 링크가 보이면 눌러 본다.

## 성공 판정 신호 (관찰 가능)
- 문서 탭이 정상적으로 늘어난다(1개 → 2개) — 위험한 내용이 있어도 여는 것 자체는 막지 않는다.
- 미리보기 안에 실행 가능한 스크립트 요소가 하나도 없다.
- 이미지 오류를 이용한 속성이 결과 화면에 남아 있지 않다.
- 이 문서를 열거나 안의 링크를 눌러도, 페이지 전역에 공격이 성공했음을 나타내는 표시(전역 변수 등)가 전혀 생기지 않는다.

## 부정/엣지 케이스
"눌렀을 때 스크립트를 실행하려는 링크"가 핵심 부정 케이스다 — 태그만 지우고 링크의 스킴(주소 형식)을 놓치는 구현이라면 이 링크를 눌렀을 때만 공격이 성공한다.

## 결과 출력 (필수 계약)
마지막 줄에 정확히 한 줄로 출력한다:
- 성공: `E2E_RESULT=PASS`
- 실패: `E2E_RESULT=FAIL: <짧은 사유>`
