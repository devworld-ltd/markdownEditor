# E2E 시나리오: 파라미터 없이 평소대로 쓴다 — 네트워크 0건 (E2, AC-2)

대상 앱: {base_url}/ (파라미터 없는 기본 진입)

## 목표
주소에 아무 파라미터도 없이 평소처럼 앱을 열었을 때는 이 새 기능(F-90/F-91) 때문에 어떤 외부 요청도 나가지 않고, 확인 대화상자도 뜨지 않는다. 앱은 평소와 똑같이 편집·미리보기가 된다.

## 사전조건
없음. 로그인이 없는 앱이다. e2e_user/e2e_pass 는 사용하지 않는다.

## 수행 단계 (순서대로, 순수 자연어)
1. 파라미터 없이 앱 첫 화면에 진입한다.
2. 편집 영역에 `hello`를 입력한다.
3. 약 0.4초 기다린다.

## 성공 판정 신호 (관찰 가능)
- 진입부터 지금까지 이 앱 자신이 아닌 외부 사이트로 나간 요청이나 `/api/`로 시작하는 요청이 한 건도 없다.
- 확인 대화상자는 화면에 열려 있지 않다.
- 미리보기 영역에 "hello"라는 글자가 보인다.

## 부정/엣지 케이스
`?url=`을 붙이되 값이 완전히 빈 채로(`?url=` 만) 진입해도 위와 같다 — 요청 0건, 확인 대화상자 없음, 알림도 없음. 빈 값은 파라미터가 없는 것과 동일하게 취급되어야 한다.

## 결과 출력 (필수 계약)
마지막 줄에 정확히 한 줄로 출력한다:
- 성공: `E2E_RESULT=PASS`
- 실패: `E2E_RESULT=FAIL: <짧은 사유>`
